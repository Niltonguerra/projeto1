## como rodar o projeto:
- usar o comando ``make help`` para poder ver os comandos de suporte para gerenciar o projeto.

## o que esse service faz?
- esse service é responsável por controlar o crawler para obtenção de dados das fontes brapi,banco central,cvm e ibge 
no ciclo de vida do bounded context responsavel por fazer a análise de ações e gerar scores.
